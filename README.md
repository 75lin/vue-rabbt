# vue-rabbit

技术栈： Vue3、Pinia、Vue-Router、Element Plus、Vite、Axios、Sass、VueUse

项目描述： 面向 C 端用户的电商前台项目，覆盖首页推荐、商品分类、二级分类筛选、商品详情、SKU 规格选择、购物车、订单结算、支付、会员订单等核心购物流程，实现从浏览商品到下单支付的完整业务闭环。

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```
